Important: Compare responses for the same service date and similar time window. RailFeed’s live_board usually starts at the current time unless full_day=1 is selected, so an 11:00 train can legitimately be absent from a later afternoon result. Absence alone is not proof that the service was invalid. RailFeed's public “Try it” is for diagnostics; its supported production API requires a key.
